# OPCraft · Descargas oficiales

Actualizador del pack Normal para Minecraft 1.20.1 Forge.

[Descargar la beta para Windows x64](https://github.com/kurt1804/opcraft-distribution/releases/tag/v0.1.0-beta.2)

**La beta es el programa, no el modpack completo.** El catálogo estable de archivos del pack sigue en revisión y todavía no está publicado. El programa no instalará una versión incompleta.

Extrae todo el ZIP y abre `OPCraft-Actualizador.exe`. Incluye .NET, funciona sin administrador y permite seleccionar la carpeta de juego del Launcher Oficial, TLauncher o Prism. No inicia el juego ni gestiona cuentas.

La publicación contiene SHA256SUMS.txt y VALIDACION.json. Pasaron 36 pruebas aisladas; todavía falta validar el catálogo real y otros equipos. Esta beta no tiene firma Authenticode.

Este repositorio público contiene únicamente distribución, documentación y los catálogos que hayan sido revisados. El código del actualizador se conserva en un repositorio privado del propietario. No se publican claves privadas, cuentas ni mundos.
